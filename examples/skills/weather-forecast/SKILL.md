# 天气预报

## 什么时候用

用户问某个城市接下来几天的天气。**只覆盖未来 3 天**，而且只覆盖 Open-Meteo 有数据的城市：
问历史天气、问一个月以后、问"哪个城市最适合度假"都不在它的范围内——那几种情况下如实说做不到，
不要拿一次预报的数据去推。

## 怎么跑

脚本在技能目录的 `scripts/` 下，目录路径是工具返回的第一行（`Base directory for this skill:`）。
用 `Bash` 照抄这一条（`{baseDir}` 会被替换成那个目录）：

```
bash {baseDir}/scripts/run.sh 深圳
```

城市名用中文或英文都行（`深圳` / `Shenzhen`）；带空格的英文名要加引号：`"New York"`
（这层没有 shell 替你分词）。

## 期望的输出

```
深圳市（China）未来 3 天：
  2026-11-19  最高 26℃  最低 19℃  降水概率 10%
  …
```

退出码 0 且 stdout 非空才算成功。**"没找到这个城市"（退出码 1）不是错误，是输入问题**：
换成更常见的写法再试一次，仍然不行就告诉用户查不到，不要自己编一个温度。

## 不要做的事

- 不要拿这份输出做推测（"所以下周会下雨"）：它只有 3 天。
- 不要在没有网络的环境里重试三次以上：退出码 1 且输出是"查天气预报失败：…SSL…"就是出网不通，
  直接说明情况。
- 不要为了凑齐格式补一个没查到的城市。
