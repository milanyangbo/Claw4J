# 上周成交额周报

## 口径（先确认，再动手）

- 成交额 = `sum(order_item.amount)`，`status <> 'CANCELLED'`，已取消的订单不计入。
- 上周 = 半开区间 `[date_trunc('week', current_date) - interval '7 days', date_trunc('week', current_date))`。
- 区域代码：`east`=华东，`south`=华南，`north`=华北。写中文区域名不会报错、只会返回 0 行。

## 步骤

1. 用 `querySales` 按区域分组查上周成交额，一次一条 SQL，不要逐个区域查。
2. 拿到结果后按下面格式输出；查不到的区域写“未查到”，不要留空、也不要猜一个数。
3. 最后加一行合计，并点明环比口径需要上周之前的数据（这一版不查）。

## 输出格式

```
上周成交额（<起始日期> ~ <结束日期>）
  华东：<金额>
  华南：<金额>
  华北：<金额>
  合计：<金额>
```

## 不要做的事

- 不要为了“看起来完整”补一个没查到的数字。
- 不要用脚本包去算这些数：这一层的授权是查库，不是跑脚本。
