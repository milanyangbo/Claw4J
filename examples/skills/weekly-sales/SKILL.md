# 成交额周报

## 口径

成交额、区域代码、区间怎么算按**部门口径**算——那一段由部署的人设给出（`examples/agents/glossary/metrics.md`），
这里不再抄一遍。同一句话抄在两个地方，改一处必漏一处，而漏掉的那一处会让两份周报对不上。

**如果这次对话里没有看到那段口径，先问一句"按哪个口径"，不要自己挑一个。**
宁可多问一轮，也不要交一份算法来路不明的周报。

**区间就用用户给的起止日期**，别自己换算成“上周”“最近七天”这种相对说法：换算一次就把口径
交到了时间手里，隔一天跑出来的数就不一样了。

## 步骤

1. 用 `querySales` 按区域分组查这个区间的成交额，一次一条 SQL，不要逐个区域查。
2. 拿到结果后按下面格式输出；查不到的区域写“未查到”，不要留空、也不要猜一个数。
3. 最后加一行合计，并点明环比需要紧邻的上一个同长区间（这一版不查）。

## 输出格式

```
成交额（<起始日期> ~ <结束日期>）
  华东：<金额>
  华南：<金额>
  华北：<金额>
  合计：<金额>
```

## 不要做的事

- 不要为了“看起来完整”补一个没查到的数字。
- 不要用 `Bash` 去算这些数：这一层的授权是查库，不是跑命令。
