# 维修价目表

保外维修的收费口径。保修期内的判定见 `warranty.md` 与 `warranty-claim.md`，不在本表范围内。

## 工时

每台 240 元，按次计，不按小时。一次上门修多处故障只收一次工时。
返修的工时按 120 元计——返修不用上门，客户自己寄。

## 常见项目

| 项目 | 收费 | 备注 |
| --- | --- | --- |
| 更换打印头 | 工时 120 + 打印头按目录价 | A1 与 B2 不同价，报价前查目录 |
| 更换胶辊 | 工时 120 + 胶辊按目录价 | |
| 更换主板 | 工时 240 + 主板按目录价 | 需要重新写入 SN，返厂做 |
| 电源适配器 | 只换不修，按目录价 | 非原厂电源导致的损坏属人为 |
| 结构件修复（外壳、支架） | 工时 240 + 材料 | 变形严重的不修，建议换机 |
| 进水 / 进液的整机处理 | 工时 240 + 材料，另加检测费 100 | 不保证修好，先检测后报价 |

## 报价与确认

先检测后报价，客户书面确认再动工。未确认就修的，客户可以拒付——
这条不是保护客户，是保护我们：口头同意在争议时不算数。

修好后 90 天内同一故障复发免费重做（`warranty-claim.md`）。

## 不值得修的情况

维修报价超过同型号新机价格的 60%，建议换机，不再修。这不是为了卖新机：
到这个比例，机器其他部件也接近寿命末期，修好这里坏那里，客户体验更差。

判断由工程师给，最终选择权在客户。客户坚持要修，照修，报价单上注明"已告知性价比"。

## 保修期内也收费的三种

保外才收费是常识，但三种情况即使在保修期内也要收：

| 情况 | 收什么 |
| --- | --- |
| 人为损坏（跌落、进液、私拆、非原厂电源） | 全套：工时 + 配件 |
| 超负荷使用（连续打印超日均标称） | 全套，且在记录里标注 |
| 只检测未维修 | 检测费 100 元，客户放弃维修时收 |

第三种最容易吵。客户把机器寄过来、检测完说"不修了"，这 100 元要不要收？
收。检测本身消耗了工程师时间与设备，不收的话"免费检测"会被当成询价工具。
但要在申请返修时就说清楚，不能等客户说不修了才提。

## 报价单要写清五项

一张合格的维修报价单，缺一项后面都可能返工：

1. **故障现象与检测结论**。"主板损坏"不是结论，"主板 U3 供电模块击穿，因外接非原厂电源"
   才是。
2. **更换件清单与单价**。按目录价，不按"市场价"。
3. **工时与依据**。上门 240、返修 120，写清是哪种。
4. **保修承诺**。同一故障 90 天内复发免费重做（见"报价与确认"）。
5. **不修的替代方案**。换机折价、以旧换新分别多少钱，让客户有比较。

第 5 项经常被省掉。省掉的结果是客户拿报价去别处比，然后回来问"那我不修了，机器怎么处理"，
又一轮沟通。

## 批量维修

同一客户一次送修 5 台以上的，工时按 8 折计，配件不打折。理由是批量送修省的是我们的
调度与运输成本，不是配件成本。

批量维修要出汇总报价单，一台一行，最后给合计。只给合计的报价单，客户财务没法入账——
每台设备是单独的固定资产，要单独计价。

## 维修与换机的临界

除了"超过新机价 60%"这条，还有两个信号说明该换机了：

- **同一台设备 12 个月内维修费累计超过新机价 30%**：这台的剩余寿命已经不值这个投入。
- **配件已停产**：修好这次，下次坏了没件（`product-discontinuation.md`）。

两个信号都出现时，主动建议换机并给以旧换新的折价（`trade-in.md`）。这不是推销，
是让客户少花一次冤枉钱——而客户会记住这一点。
