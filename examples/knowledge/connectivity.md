# 连接与协议

## 四种接法

**网口**：默认方式，支持固定 IP 与 DHCP。推荐固定 IP，因为打印机的 IP 一变，
装了驱动的电脑就找不到打印机，现场表现是"昨天还能打，今天不行"。
**USB**：单机直连，最稳，不适合共享。
**串口**：老产线设备常用，注意波特率与流控要和上位机一致。
**蓝牙**：仅 K4 便携机型，有效距离 10 米以内，中间不能有金属遮挡。

## 驱动与指令集

驱动负责把文档转成打印机认识的语言。ZPL 与 TSPL 是两套指令集（`printer-specs.md`），
选择哪个取决于客户的上位系统：SAP 类系统多用 ZPL，国产 MES 多用 TSPL。

发送原始指令（不经驱动）时要用透传模式，否则驱动会给指令加一层格式，
现场表现为"指令发过去了但没反应"。

## 网络排查顺序

先 ping 通不通，再看端口 9100（ZPL 透传默认端口）开不开，最后才看驱动。
顺序反了会浪费很多时间在重装驱动上。

IP 冲突是"时好时坏"的典型原因：两台设备抢同一个地址，谁先上线谁能用。
遇到"偶发打不出来"，先查 ARP 表里有没有重复 MAC。

## 多机部署

超过 10 台时不要逐台配 IP，用 DHCP 保留地址 + 打印服务器队列。逐台配的问题是
换机、加机都要人工介入，而且没人维护那张 IP 表。

机台旁的标签建议贴 IP 与设备编号，维修时不用进系统查。
