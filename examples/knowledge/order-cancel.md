# 订单取消

## 按阶段收不收钱

| 阶段 | 能否取消 | 费用 |
| --- | --- | --- |
| 已下单、未审核 | 可取消 | 无 |
| 已审核、未排产 | 可取消 | 无 |
| 已排产、未发货 | 可取消 | 按订单金额 10% 收取排产损失 |
| 已发货 | 不能取消，按退货处理 | 见 `after-sales.md` |

"已排产"的判定是系统状态，不是销售口头说"还没做"。销售说"应该还来得及"不算，
以系统工单状态为准。

## 三类订单不能取消

1. **定制机**（`customization.md`）：一旦样品确认即不可取消，已发生的打样、模具、投料费用不退。
   样品确认前可以取消，但要收已发生的打样费。
2. **清库机**：清库订单不接受取消，也不接受换货（`product-discontinuation.md`）。
3. **出口订单**：报关后不能取消，退货要按进口流程办，税费由客户承担。

## 我方原因导致的取消

缺货超过 15 天（`stock-availability.md`）、或我方无法按期交付且协商不成的，
客户可无责取消，不承担任何费用，预付款全额退还。

这种情况下不要试图收"排产损失"——是我方交不出货，收费只会把一次延期变成一次投诉。

## 取消后的钱

- 未开票的：预付款原路退回，3 个工作日内发起（`advance-payment.md`）。
- 已开票的：先冲红（`invoice-reissue.md`），冲红完成后 3 个工作日内退款。
- 有返利额度的：取消的订单从返利基数里扣减（`rebate-calculation.md`），
  已计入当季基数的，下季度扣。

## 不要把取消做成退货

两个动作的账务处理不同：取消是"交易没发生"，退货是"交易发生后又撤销"。
系统里取消要选"订单取消"，不要选"退货"——选错会导致库存凭空多出一笔入库，
月末盘点对不上（`cycle-count.md`）。
