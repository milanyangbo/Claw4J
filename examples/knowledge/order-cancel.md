# 订单取消

## 按阶段收不收钱

| 阶段 | 能否取消 | 费用 |
| --- | --- | --- |
| 已下单、未审核 | 可取消 | 无 |
| 已审核、未排产 | 可取消 | 无 |
| 已排产、未发货 | 可取消 | 按订单金额 10% 收取排产损失 |
| 已发货 | 不能取消，按退货处理 | 见 `after-sales.md` |

"已排产"的判定是系统状态，不是销售口头说"还没做"。销售说"应该还来得及"不算，
以系统工单状态为准。

## 三类订单不能取消

1. **定制机**（`customization.md`）：一旦样品确认即不可取消，已发生的打样、模具、投料费用不退。
   样品确认前可以取消，但要收已发生的打样费。
2. **清库机**：清库订单不接受取消，也不接受换货（`product-discontinuation.md`）。
3. **出口订单**：报关后不能取消，退货要按进口流程办，税费由客户承担。

## 我方原因导致的取消

缺货超过 15 天（`stock-availability.md`）、或我方无法按期交付且协商不成的，
客户可无责取消，不承担任何费用，预付款全额退还。

这种情况下不要试图收"排产损失"——是我方交不出货，收费只会把一次延期变成一次投诉。

## 取消后的钱

- 未开票的：预付款原路退回，3 个工作日内发起（`advance-payment.md`）。
- 已开票的：先冲红（`invoice-reissue.md`），冲红完成后 3 个工作日内退款。
- 有返利额度的：取消的订单从返利基数里扣减（`rebate-calculation.md`），
  已计入当季基数的，下季度扣。

## 不要把取消做成退货

两个动作的账务处理不同：取消是"交易没发生"，退货是"交易发生后又撤销"。
系统里取消要选"订单取消"，不要选"退货"——选错会导致库存凭空多出一笔入库，
月末盘点对不上（`cycle-count.md`）。

## 部分取消

一单多型号时，经常只取消其中几项。规则按"取消部分占整单金额的比例"判断：

- 取消部分不足 30%，且剩余部分照常执行的：不收排产损失，只按实际取消的型号重排产。
- 取消部分 30% 以上：按取消部分的金额收 10% 排产损失——因为整单的排产计划要重做，
  不是把某几行划掉就行。
- 取消后整单金额低于 1 万元的：视同整单取消，按上表处理，不保留"部分执行"。

第三条是防拆单：把一单拆成几次部分取消，每次都不足 30%，实际等于整单取消。
系统按订单号累计，同一订单号的部分取消合并计算。

## 取消还是换货，怎么选

客户说"这批不要了"，先分清楚是"不要这个型号"还是"这台机器有毛病"：

| 客户真实意图 | 该走哪个流程 |
| --- | --- |
| 选错型号了 | 取消（未排产）或退货（已发货），不能走换货 |
| 型号对，但收到的是坏的 | 换货（`exchange-policy.md`），30 天内非人为损坏 |
| 项目取消了，设备用不上了 | 取消，按阶段收费 |
| 嫌贵，想压价 | 哪个都不走，走价格谈判（`pricing-objection.md`） |

最后一行听着不好听，但确实是常见情形：客户说要取消，实际是在谈条件。这时候如果直接
进取消流程，价格谈判的空间就没了。正确做法是先问"是项目有变化，还是价格上还有考虑"。

## 月末与年末的特殊处理

两个时点的取消会牵动报表，规则单独说：

- **月末最后两个工作日**：已开票的订单取消，必须同步做发票冲红，否则当月收入虚增。
  财务会卡住这类订单，不在月底最后一天放行。
- **12 月 31 日前后**：跨年取消按实际发货与开票时点判断归属年度（`invoice-reissue.md`）。
  12 月开票、次年 1 月取消的，冲红冲当年，账务按跨期处理，要报财务总监。

这两个时点不要"先取消、手续后补"。报表关账之后补手续，改的就不是一张单，是一整月的数。

## 取消申请的留痕

取消必须由客户书面提出（邮件、盖章申请、IM 文字均可），口头取消不算。
理由是排产损失要据此主张：客户口头说取消、我方停了产，事后客户否认，
这笔损失只能自己承担。

留痕还要写清"取消原因"与"客户确认的费用金额"。只写"客户要求取消"的申请，
财务在核算排产损失时无从判断，会一律按最低档处理。
