# 术语表

跨部门沟通里最容易各说各话的一批词，统一在这里。**这里只给定义，不给数字**——
天数、金额、比例都在各自的政策文档里，以那边为准。

| 术语 | 含义 |
| --- | --- |
| 退货 | 解除交易、退还货款。窗口按地区不同，见 `after-sales.md` |
| 换货 | 换一台同类设备，不退款。期限见 `warranty.md` |
| 保修 | 免费维修，不换不退。整机与易损件期限不同，见 `warranty.md` 与 `printer-specs.md` |
| 保外 | 超出保修期或属人为损坏，维修要收费 |
| 备机 | 整台设备临时借用，用完归还（`spare-parts.md`） |
| 备件 | 零件，装上就属于客户（同上） |
| 易损件 | 打印头、胶辊、切刀。寿命短，保修期单独算 |
| 耗材 | 标签纸、碳带。用一次就消耗掉，不保修 |
| 碳带 | 热转印的色带。分蜡基、混合基、树脂基，耐刮性依次增强 |
| 热敏 | 不用碳带，纸本身遇热变色。怕高温与摩擦，长期保存不如热转印 |
| TTO | 热转印套印（Thermal Transfer Overprint），在包装膜上打码的方式 |
| DPI | 每英寸点数，分辨率。203 与 300 最常见 |
| SN | 设备序列号，机身铭牌上，追溯用 |
| RMA | 返修单号，格式见 `rma.md` |
| 8D | 八步问题解决报告，用于重大质量投诉（`quality.md`） |
| AQL | 抽检合格判定水平，我们不用这套，按固定比例抽（`quality.md`） |
| FIFO | 先进先出。耗材必须遵守，胶会老化 |
| 呆滞 | 180 天不动销的库存（`inventory.md`） |
| 账期 | 从签收/验收日起算的付款宽限（`settlement.md`） |
| 冲红 | 用红字发票冲销原发票，退款与重开的前置动作 |
| 返利 | 按提货额给的年度/季度返还，经销渠道专属（`channel-policy.md`） |
| 串货 | 跨授权区域销售，经销渠道的违规行为 |
| 价格保护 | 提货后目录价下调的差额补偿 |
| 框架合同 | 约定年度总量与条件的长期合同，具体订单另行下单 |
| 履约保证金 | 中标后交纳、保证履约的款项 |
| 首件 | 批量生产前确认的第一件样品 |

缩写第一次出现在合同或对外文件里要写全称，内部沟通可以只用缩写。
