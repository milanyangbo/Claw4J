# 客户编码规则

## 编码结构

`C` + 区域码（2 位）+ 年份（2 位）+ 序号（4 位），例如 `C-EA-26-0187`。

| 段 | 含义 | 取值 |
| --- | --- | --- |
| C | 客户（固定） | C |
| 区域码 | 归属区域 | EA 华东、SA 华南、CA 华北、CW 华中、SW 西南、NE 东北 |
| 年份 | 建档年份 | 两位，如 26 |
| 序号 | 该区域该年的流水 | 0001 起 |

区域以**建档时的归属**为准，客户搬家或换客户经理不改编码。改编码等于换了个客户，
历史订单、额度、返利全要迁移，得不偿失。

## 一客一码

同一法人主体只能有一个编码。集团客户下有多家子公司的，子公司各自建档、各自一个编码，
不共用母公司的编码与额度——子公司是独立法人，债务不互担。

反过来，同一家客户在不同区域有多个收货地址的，不新建编码，在原有编码下加收货地址。
这一条经常被违反：销售为了归属方便，给同一个客户在不同区域各建一个码，
结果同一个客户在两个区域各拿一份额度，实际风险翻倍。

## 合并与拆分

- **合并**：同一法人重复建档的，提交合并申请，保留最早的编码，其余停用。
  合并后历史订单归到保留的编码下，返利基数合并计算。
- **拆分**：一家客户分立为两家法人的，新主体新建编码，旧编码保留但标记"已分立"，
  不再接新单。旧编码下的未结订单按实际履约主体结算。

合并与拆分都需财务确认，因为涉及额度与返利的重算（`credit-limit.md`、`rebate-calculation.md`）。

## 编码与开票

开票信息（名称、税号、地址电话、开户行账号）挂在编码下，改编码不影响已开发票。

客户改名（未改法人）的，更新编码下的名称即可，不用新建编码；
但要在备注里保留原名，否则历史发票与对账单对不上。
变更法人主体的，必须新建编码——税号变了就是另一个纳税人。

## 停用与复用

连续 24 个月无订单的编码自动停用。停用不等于删除，历史数据仍可查。

停用的编码**不复用**。客户重新合作时新建编码，旧编码标注"原编码 C-XX-XX-XXXX"。
不复用的理由：复用一个已经停用两年的码，中间那段空白会被后来的对账人当成"漏记"。
