# 固件升级与回滚

## 升级方式

三种，按场景选：

| 方式 | 适用 | 需要 |
| --- | --- | --- |
| U 盘升级 | 单台、现场 | U 盘（FAT32）、固件文件 |
| 工具批量升级 | 多台、同网段 | PC + 升级工具，扫描网段自动发现 |
| 远程升级 | 已开通远程支持的客户 | 设备在线，且客户书面授权 |

远程升级必须书面授权，不接受电话同意。升级过程中设备会重启，产线停机的责任要事先说清。

## 升级前必须做

1. **记录当前版本**：机身菜单或 web 页面可查，记下来。
2. **备份配置**：IP、打印参数、模板、校准值。配置丢了，光重新校准就要半小时。
3. **确认电源稳定**：升级中断电是唯一会导致变砖的操作，UPS 或至少确认不是临时线路。

## 回滚

**能回滚，但要满足两个条件**：

- 硬件版本支持旧固件（1.2.x 之后硬件有改动，1.1.x 的固件刷不回去）；
- 有该型号的旧版固件文件（官网只提供最新版，旧版要找技术支持要）。

回滚会**清空配置**，这一点与升级不同：升级保留配置，回滚不保留。回滚后要重新配置与校准。

回滚的典型场景：新版固件在特定标签材质上出现断针补偿异常、或与客户的 ERP 打印服务不兼容。
这类问题通常在新版发布后两周内暴露，所以不建议客户在发布当周就升级生产设备。

## 非官方固件

刷第三方固件（含"破解版""免芯片版"）的机器，**整机保修直接失效**，不是"只影响固件部分"。
理由：第三方固件会改打印头的温控参数，烧头的风险转嫁给我们，这不合理。

识别方式：开机自检的版本号格式与官方不同，或 web 页面缺少签名校验项。
发现后不在现场争论，拍照记录，回公司由技术判定。

## 升级失败怎么办

分三种：

- **卡在升级界面**：断电重启，重新刷。多数是文件损坏，换一个 U 盘再试。
- **开机无反应（变砖）**：只能用烧录器刷（工厂或区域技术中心），客户现场救不回来。
  保内免费，保外按维修收费（`warranty.md`）。
- **能开机但功能异常**：先回滚，回滚无效的按硬件故障处理。

## 版本策略

主版本（1.x → 2.x）每年一次，含功能变更，升级前要评估兼容性。
次版本（1.2 → 1.3）每季度，修缺陷为主，建议升级。
补丁版本（1.3.1）随时，修安全或数据问题，立即升级。

版本说明会写明"是否影响现有模板"，影响模板的升级要提前通知客户重新验证。
