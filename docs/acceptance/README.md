## 日期只是标签，不是门槛

- **要跑随时跑**，不用等某个日子，也不必修文档里任何路径。
- **原文命令不会自动写到这里**：文档里的起实例命令只往终端打；要留证据就自己 `tee`。
  所以明天复跑**不会覆盖** 2026-11-22 这一批。
- **库按用途分，不按日期分**：`claw4j_accept_g`（G/H）、`claw4j_demo`（三场戏）明天照用；
  想从零开始就 drop 再 create，命令在批次 README 的"收掉"一节。
- `*.log` 不入库（见根 `.gitignore`），留多少都不弄脏 `git status`。

## 要留新一批

```bash
D=docs/acceptance/$(date +%F)          # 例：docs/acceptance/2026-11-23
mkdir -p "$D"

# 起实例时把输出接到当天目录
java -jar claw4j-app/target/claw4j-app-0.1.0-SNAPSHOT.jar <参数…> 2>&1 | tee "$D/demo-app.log"

# 流式那几段单独存原始帧
curl -sN … | tee "$D/demo-a2.txt"
```

新目录里照 2026-11-22 那份 README 抄一份索引，写上"这一批验了什么、留下了哪些数"——
**索引比日志重要**：日志能重跑，当时为什么跑、看到什么，只有索引记得住。
