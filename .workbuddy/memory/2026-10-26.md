### 实现 05 的"无凭据那一档"（飞书 SDK 绑定 + 条件装配，真链路待凭据）
- 新增子包 `channel.feishu.sdk`：`FeishuChannelProperties`（凭据 / 角色→授权 / users 登记 open_id）、

- 三个坑（都写进票 05 的进展段）：
  ① **Boot 4 的 JSON 是 Jackson 3**（`tools.jackson.databind`）。`com.fasterxml.jackson.databind`
  根本不在 classpath 上，抄来的代码直接编译失败；`JacksonException` 已是 unchecked。
  ② **`ApplicationContextRunner.run()` 不抛启动失败**，失败会挂到 `context.getStartupFailure()`，
  必须 `assertThat(context).hasFailed()`。我先用 `assertThatThrownBy` 包它 → 永远"没抛" →
  误判成 `@PostConstruct` 没跑，白改了一轮 `InitializingBean`，最后又改回去。
