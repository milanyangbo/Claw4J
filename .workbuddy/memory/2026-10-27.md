### code-review（9121078...HEAD，双轴）修掉的问题
- **ArchUnit 规则是空的**：`resideInAPackage("com.larksuite..")` 写错了——oapi-sdk 的 Java 包是
  `com.lark.oapi`（`com.larksuite.oapi` 只是 Maven groupId）。这类规则失效不报错，绿的，
  等于"以为有人守其实没有"。改法不是改对包名，而是**换成 allowlist**：
  `resideOutsideOfPackages("java..", "org.slf4j..", "io.github.claw4j..")`，不跟厂商包名走。
  domain 的六条厂商黑名单同样换成 `resideOutsideOfPackages("java..", "io.github.claw4j.domain..")`。
  两条都做了变异验证（塞 `com.lark.oapi.ws.Client` 字段 → 红 1 次；收紧到 `java.util..` → 红 68 次）。
- **`MessageSplitter` 空列表越界**：表头自超限但无数据行时 `splitOversized` 返回空，
  `pieces.size()-1 = -1` → `subList(0,-1)` 抛 IndexOutOfBounds，整段回答变成一句"处理失败"。
  兜底：切不出来就整块发（平台拒收这一条，别的段照常送达）。变异验证：去掉兜底那条用例红。
- **`roles.*.users` 填错文件**：票 05 说填 `application-local.yml`（gitignore），`.env.example` 却说填
  `application.yml`——照做会把真实 open_id 提交进仓库。三处一起改：`.env.example`、
  `application-local.yml.example` 补一节只写 `users`（授权范围仍只在 application.yml 一份，不复制）。
- **"全员没有权限"启动时不出声**：凭据齐、roles 全空时通道照样就绪，现象与"服务没起来"一样。
  补 `FeishuChannelProperties#warnIfNobodyIsRegistered()`（@PostConstruct 里 WARN），
  顺带让原本没人调用的 `configured()` 有了用处。两条用例（有凭据要说、没凭据别吵）。
  **刻意不 fail-fast**：不填 open_id 就起不来，用户永远拿不到日志里那个 `ou_...`，成了死锁。
- Java 里那份默认角色删掉（与 application.yml 逐字重复，两处说同一件事）。
