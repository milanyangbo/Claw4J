# 07: 真实模型联调与文档收尾

**What to build:** 前面六张票都是在脚本化假模型上验的。这一张用真实供应商把整条闭环跑一遍，并把本轮新定的决策与新的演示方式写进文档。两个真实 key（DeepSeek 与通义）都已在本机 `.env` 里，随手可用。

**Blocked by:** 03, 04, 05, 06

**Status:** ready-for-agent

**Demo:** 用真实模型跑一遍完整闭环，curl 的真实输出（同步与流式）录进 README，换一个角色头演示没权限时拿不到。

- [ ] 真实模型跑通同步与流式，两家各一次（`CLAW4J_MODEL_PRIMARY` 切换）
- [ ] 主备降级在真实链路上复现一次（把主的 base-url 指到没人听的端口，看请求落到备）
- [ ] README：curl 示例换成真实闭环（问"上周华东区成交额"拿到数）、模型切换说明、测试计数更新
- [ ] GLOSSARY：补 M1 新增的术语（`@Tool`、会话 / Chat ID 的区别、脱敏）
- [ ] ADR 留痕：本轮在票内定下的三个决策——schema 迁移方式、只读约束的落法、自纠错重试上限——写进对应 ADR，不要留在 `.scratch/` 里
- [ ] 真实调用的集成测试用 profile 隔离，默认不进 CI（ADR-0006、ADR-0008）

**注意**：真实调用不进 CI，它是一次性的闭环证明，不是回归基线。回归基线是前六张票留下的那些测试。

**顺手对一遍**：M0 结束时是 64 个测试。这一张票收尾时要确认新增的测试数被写进 README，且 `mvn verify` 全绿。
